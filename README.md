# 空间文化与导视设计

`spatial-culture-wayfinding` 是面向学校、企业、社区、园区和公共服务场所的设计 SKILL。它用同一套点位编号串联动线、文化墙、标识牌、文案、效果图、报价和验收。

## 快速开始

1. 下载或克隆本仓库，保留 `SKILL.md`、`assets/` 和 `references/` 的相对位置。
2. 在支持 Agent Skills 的工具中按其规则添加整个目录，然后调用 `spatial-culture-wayfinding`。普通对话中也可以提供 [SKILL.md](SKILL.md) 和本轮需要的参考文件。
3. 提供项目类型、空间用途和现场照片。已有平面图、品牌规范、点位清单或正式文案时可一并提供。只有照片时，可以先做概念布局并标记待复尺点位。

### 调用示例

> 使用 spatial-culture-wayfinding，为这个社区服务中心整理入口形象、办事导视和功能室门牌。按照片标明建议点位、安装依据和待核尺寸，输出 16:9 汇报方案。单位名称和办理流程暂用占位。

> 使用 spatial-culture-wayfinding，以已确认效果图为底稿，只更换右侧公示栏文案。核对其余标识、建筑关系和画幅，并列出画册中需要同步更新的页面。

## 交付阶段

| 阶段 | 可交付内容 |
| --- | --- |
| 概念与汇报 | 动线和点位建议、方案效果图、分类画册。区分实景模拟与典型场景。 |
| 询价与打样 | 物料数量、参考规格、报价口径及样板检查项。 |
| 生产与安装 | 根据复尺、审定文案和样板出尺寸图、生产文件与安装节点。 |
| 验收与维护 | 逐件验收记录、竣工资料、画芯或备件规格与换刊记录。 |

## 项目模板

复制空白 TSV 后再填写，可用表格软件打开。点位编号对应安装位置，物料编号对应单件实物，款式编号对应可复用规格。

| 模板 | 用途 |
| --- | --- |
| [点位、复尺与报价表](assets/points.tsv) | 登记实物、基层、尺寸、材质、节点和计价范围。 |
| [文案台账](assets/copy.tsv) | 记录正文来源、版本、审定和更新责任。 |
| [变更与图源表](assets/revisions.tsv) | 记录锁定底稿、允许变更项和总览同步情况。 |
| [安装验收表](assets/acceptance.tsv) | 核对逐件安装、阅读、换刊及整改结果。 |
| [来访路线与导视校核表](assets/routes.tsv) | 按来向核对决策点、箭头、可见面和确认牌。 |
| [维护与换刊表](assets/maintenance.tsv) | 记录画芯、备件、责任人和更换状态。 |

更多说明见[深化与交付参考](references/delivery.md)、[视觉与交付规格](references/visual-system.md)和[场景验收用例](references/scenarios.md)。施工按现场复尺、审定文案和确认节点执行，消防与疏散标识以项目核准资料为准。
