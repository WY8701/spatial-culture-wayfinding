# 场景验收用例

用于人工复核 SKILL 的交付预期，可按需拿真实任务验证。

| 场景 | 合格输出 | 要查的常见遗漏 |
|---|---|---|
| 社区服务中心只有照片 | 提供入口、服务大厅和窗口导向概念稿，列出可确认的点位，标注墙面尺寸和转角视线待核 | 旧项目的单位名称、主题、制度、箭头残留。把估算尺寸写成实测。 |
| 已锁定画册，只让移除入口垃圾车 | 以核准入口图为基准，仅更改目标对象及遮挡区域。按任务范围同步《入口总览》的关联版本，说明是否已更新画册 | 效果图重绘时误改门头、台阶、镜头或文字。把单图改稿描述成已更新全册。 |
| 同一墙面三块展板，现场尚未复尺 | 一个点位、三个物料编号，询价注明参考版幅、单位、数量依据与计价范围。审定正文或尺寸不足的生产项保持待确认 | 点位数量被当成实物数量，漏算安装、运输或出血。正文占位进入生产稿。 |
| 不同来向共用一处走廊转角 | 分来向走查箭头与可见面，转向后按需设置确认牌。明确消防箭头按核准路线复核 | 左右箭头在相反来向沿用同一稿。尺寸或位置影响通行、门扇开启。 |
