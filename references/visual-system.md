# 视觉与交付规格

## 开始生产前记录项目样式

| 维度 | 记录内容 |
|---|---|
| 颜色 | 主色、辅助色、底色与正文色。记录屏幕色值及实体打样编号。用对应材料和现场灯光确认样板。 |
| 文字 | 中文、英文及数字样式，单位正式称谓，楼层及房号写法。标题、正文和辅助信息统一字级，按现场距离检查阅读。 |
| 图标与箭头 | 图标来源、是否允许使用、含义及方向。通用导视统一造型，消防、警告和无障碍符号按适用要求确认。 |
| 物料版式 | 门牌、公示栏、双层制度牌和文化墙各定义一个基础款式。固定内容区、可换区、编号区与尺寸调整规则。 |
| 项目例外 | 现有品牌标准、已定样式与必须保留的原有标识。图面冲突时记录采用依据和受影响点位。 |

用一张项目样式表集中维护这些值。通用指南里保留字段和方法。品牌色、单位名称、术语、图标授权、字号和成品尺寸按项目确认。

## 文件与版本

- 汇报图可用平面或生成式建筑可视化。需保持真实场地几何时优先沿用校核过的底图或模型。图中准确文案通过可编辑文字排版。
- 生产交付应约定文件格式与比例、色样、出血、裁切或雕刻轮廓、固定孔位、分件标记及安装定位图。按工艺提供对应内容。
- 源文件包单独保留可编辑文字与关联图像。生产版如需文字转曲，保留同版可编辑稿，字体和图库授权按实际许可处理。
- 文件名可用「项目_物料或图号_用途_Vxx」。用途可写概念、询价、生产、竣工。项目只保留一个当前版本发布入口，记录审批日期和替换范围。
